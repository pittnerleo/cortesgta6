Política de Privacidade

Início Termos de Uso Política de Privacidade

O CortesGTA6 não tem servidor próprio: tudo fica no computador do usuário.

1. Dados usados

  • Autorização das contas (tokens de acesso do TikTok e do YouTube), recebida pelo login oficial de cada plataforma.
  • Nome de exibição da conta, apenas para mostrar ao usuário qual conta está conectada.
  • Os vídeos que o usuário escolhe enviar.

2. Onde os dados ficam

Os tokens ficam guardados somente no computador do usuário, criptografados pelo próprio Windows (DPAPI). Eles não são enviados para nenhum servidor do desenvolvedor, porque o aplicativo não tem servidor.

3. Com quem os dados são compartilhados

Com ninguém além das próprias plataformas: os vídeos vão diretamente do computador do usuário para o TikTok ou para o YouTube, pelas APIs oficiais. Nenhum dado é vendido, cedido ou usado para publicidade.

4. Dados de outras pessoas

O aplicativo não coleta dados de seguidores, comentários ou de qualquer outro usuário das plataformas.

5. Como apagar

Ao clicar em "Desconectar" no aplicativo, a autorização é apagada do computador. Apagar a pasta do aplicativo remove todos os dados. O acesso também pode ser revogado no TikTok (Configurações → Segurança → Apps) e em myaccount.google.com/permissions.
